# Studio-Index

Studio-Index is a responsive web application built with React, TypeScript, and Vite. It provides a live project interface developed for browser-based deployment.

## Live Project

- Vercel deployment: https://studio-index-ten.vercel.app

## Technologies

- React
- TypeScript
- Vite
- HTML and CSS

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
